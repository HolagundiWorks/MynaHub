# Getting started

## Create a company

1. Open AOS.
2. Choose **Create a new company**.
3. Enter the practice name, choose a folder, and name the file. AOS adds `.adms` if you leave the extension off.
4. Set an admin password of 12 or more characters and confirm it.
5. Choose **Create company**.

AOS then shows a recovery code **once**. Store it somewhere you can find later. It is the way back in if the admin password is forgotten.

## Open a company

Choose **Open an existing company**, or pick a file under **Recent**. If a recent file has moved, **Remove** clears that entry. The file itself stays where it is.

A company file can be open in one window. Close it before opening the same file somewhere else.

## Sign in

Enter the admin password and choose **Sign in**. There is no separate username on this screen.

**Forgot password? Use recovery code** asks for the recovery code and a new password. The old recovery code stops working. A new code is shown once. Store that new code.

**Switch company** closes the open file and returns to the start screen.

## What the file holds

The `.adms` file holds the records, issued PDFs, attachments, and audit history. Copy that file to move or archive the practice. AOS keeps a copy before it upgrades the file. The file is not encrypted, so keep the folder as private as the practice records inside it.
