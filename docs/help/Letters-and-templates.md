# Letters and templates

Open these from **Documents** in the menu.

## Letters

Choose **Create** and save a draft with **Ctrl+S** or **Save draft**. A draft can still be changed. An issued letter keeps the wording and layout it had on the day it was issued.

On an issued letter you can:

- **Revise** — start a new revision from the issued letter.
- **Attach signed copy** — store the signed file against the letter.
- **Mark signed** — available for an issued agreement after a signed copy is attached.
- **Cancel document** — available for an issued letter. A reason is required.

## Templates

The company file includes practice templates for proposals, agreements, and project administration. They are practice wording for an Indian architectural office. They are not official Council of Architecture forms. Read them before you issue a letter from one.

A built-in template stays as shipped. To change the wording:

1. Open **Templates**.
2. Copy the template.
3. Open the copy and edit it on the Word-style page.
4. Save. The copy is stored as a `.docx` file.

**Delete** on a template you created archives that template. Issued letters already produced from it stay in the file.

Text in `[[double brackets]]` is a prompt. Replace it before the letter is issued.
