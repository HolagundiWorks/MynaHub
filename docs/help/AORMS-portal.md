# AORMS portal

AORMS is the studio's web portal. Connecting to it is optional. O-Studio works fully without it and makes no network call until you sign in on **Office > AORMS portal**.

## Signing in
Enter the e-mail and password you use for AORMS. The password is used once to sign in and is never saved. The sign-in is the suite's shared one: it is kept in Windows Credential Manager (`AORMS/Connect`) so the other AORMS desktop apps on this computer, O-Draft and O-Metra, use it too. If one of them is already signed in, O-Studio shows **Connect O-Studio** instead. Connecting is always your choice.

Signing out clears the shared sign-in on this computer, so the other apps will ask you to sign in again.

## Pulling a project
**Load projects** lists your studio's projects. **Pull into O-Studio** adds the project to Projects and its client to Clients, if that client is not there already (matched by name, ignoring capital letters). Later, **Update from portal** changes only the project's name and site address. Nothing is sent to the portal, and nothing local is deleted.

## If something goes wrong
- *Invalid login credentials:* check the e-mail and password.
- *Sign in to AORMS on the web once:* the account has never signed in to the web portal. Do that first.
- *Plan not connected:* the studio's plan does not include connected mode. O-Studio carries on on its own.
- *You signed in on another computer:* only one computer at a time can use O-Studio with the portal. Sign in here to take it back.
- O-Studio is offline or the portal is busy: try again later. You stay signed in.
