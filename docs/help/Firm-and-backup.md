# Firm and backup

Open these from **Office** in the menu.

## Firm

**Firm** is the practice profile printed on letters and invoices: name, architect, address, email, phone, PAN, GSTIN, Council of Architecture registration, bank details, and UPI id.

Set the **GST scheme** (not registered, composition, or regular) and the **Letterhead** (classic or minimal). Choose **Save profile**, or press **Ctrl+S**. The letterhead choice is stored with each document when that document is issued.

## Security

**Security and backup** shows recent activity in the company file. **Refresh activity** loads it again. **Show audit** lists the latest events.

## Backup

1. Open **Security and backup**.
2. Enter the admin password.
3. Choose **Create backup**.

O-Studio writes a backup and shows the file name, SHA-256, size, and folder. **Show backups** lists backups already taken. Keep the backup folder as private as the company file. The backup is not a substitute for the recovery code: you still need the admin password or the recovery code to open the practice.
