App and version: installed `aad-cli 0.6.0`; engine via CLI

Area: D3 Drawing and modify

## Steps to reproduce
1. `aad-cli run --sample --cmd "line {\"points\":[[0,0],[1e308,0]]}"`
2. Observe exit code and returned handles.

## Expected
Per PLAN-O-DRAFT DRF-MOD-08: `1e308`, `NaN`, `-0` refused with a message.
