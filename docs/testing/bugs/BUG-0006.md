# BUG-0006

Severity: S2  
App: Launcher  
Test case: LNC-WIN-03  
Status: open  
Found: 2026-11-01

## Summary

The company sign-in window does not offer **Create a new company**. The welcome panel only has **Open company file…**, **Open remembered company**, and text directing users to full Kivo.

## Steps

1. Start `O-Studio.Launcher.exe`.
2. Tray → **Company sign-in…**
3. Look for create-company flow on the welcome panel.

## Expected (plan)

Create a company with name, owner, password 12+ characters; recovery code shown once.

## Actual

No create control; message “Create a new company or manage users in full Kivo.”

## Evidence

`docs/testing/runs/2026-11-01-launcher.md` (LNC-WIN-03 FAIL); `native/Adms.LoginWidget/CompanyLoginWidget.cs` `BuildWelcomePanel`.
